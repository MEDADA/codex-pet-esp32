# Security Policy

This repository primarily contains character artwork, animation assets, previews, and integration documentation.

## Reporting

Please do not publish access tokens, private keys, personal data, or other secrets in issues or pull requests. If a credential is accidentally committed, revoke it immediately; deleting the visible file does not invalidate the credential or remove it from Git history.

For security-sensitive reports, contact the repository owner through the GitHub profile rather than posting exploit details publicly.
